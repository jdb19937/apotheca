# Apotheca

Collectio bibliothecarum et instrumentorum in lingua C, sine ullis dependentiis externis.

> **Nota:** README.md ignorandum est. Anglice scriptum est ad barbaros ineruditos pecunia emungendos.

## Contenta

| Submodulum | Descriptio |
|---|---|
| **ison** | Bibliotheca ISON (JSON) — scriptor, lector, navigator per viam punctatam, schema, ISONL |
| **crispus** | Cliens HTTPS sine dependentiis — TLS 1.2, ECDHE P-256, AES-128-GCM, RSA, omnia interne |
| **face** | Instrumentum aedificationis (ut make), in lingua C |
| **ddiff** | Forma compacta differentiarum quae translationes truncorum inter fasciculos detegit |
| **insinulint** | Lintor linguae C, 13 regulae, configuratio per ISON |
| **munda** | Ludus simulationis tabularis — entia per oraculum LLM cogitant in tabula toroidali |
| **phantasma** | Bibliotheca fenestrae et inscriptionis minimalis — Cocoa, X11, GIF, MP4 |
| **sqrt** | Immersio isometrica tori plani in R3, campi stellarum, spectator interactivus |

## Aedificatio

```
face para          # initia submodula recursive
face omnia         # aedifica omnia
face purga         # purga omnia
```

## Versiones

```
face fige           # submodula ad tags ultimas checkout
face signa TAG=II   # signa apothecam (solum si omnia ad tags sunt et nulla mutationes)
```

`face firma` ad commit fixum parentis revertit. `face trahe` ad capita recentissima trahit.

## Dependentiae

Nullae externae. Solum compilator C et POSIX. Munda pendet ab ison et crispus (ut submodula). Insinulint et sqrt pendent ab ison (ut submodulum). Sqrt SDL2 requirit pro spectatore interactivo.
